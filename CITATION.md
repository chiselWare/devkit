# Citing chiselWare

If you use chiselWare in your research, please cite it as follows.

## BibTeX

```bibtex
@software{chiselware2026,
  author    = {Savage, Warren},
  title     = {{chiselWare}: A Certified Open-Source Ecosystem
               for {Chisel}-based Semiconductor {IP}},
  url       = {https://chiselware.org},
  version   = {0.8.0},
  year      = {2026},
  publisher = {Rocksavage Technology, Inc.}
}
```

## IEEE Format

W. Savage, "chiselWare: A Certified Open-Source Ecosystem for
Chisel-based Semiconductor IP," Rocksavage Technology, Inc., 2026.
[Online]. Available: https://chiselware.org

## ACM Format

Warren Savage. 2026. chiselWare: A Certified Open-Source Ecosystem
for Chisel-based Semiconductor IP. Rocksavage Technology, Inc.
https://chiselware.org

## Plain Text

W. Savage, chiselWare, version 0.8.0, Rocksavage Technology, Inc.,
2026. https://chiselware.org
